# kugitch.github.io

CHAN Ting Hin 的 GitHub Pages 主頁入口，用作整理教育科技作品、HTML 教學工具及互動教材。

## 如何新增工具卡片

1. 將 HTML app 發佈到相應 repository（例如 `LearningMaterial` 或 `Tools`）。
2. 在 `index.html` 的 `apps` 陣列新增一個物件。
3. 填寫 `title`、`description`、`category`、`repository`、`url` 及 `keywords`。
4. 如要顯示於首頁「精選應用」，設定 `featured: true`。

頁面使用純 HTML、CSS 及 vanilla JavaScript，可直接透過 GitHub Pages 運作。
