About

關於我

我是 CHAN Ting Hin，一位關注教育科技實踐的教育工作者。我的作品聚焦於 AI in Education、STEAM education、computational thinking，以及小學數學學習中的互動化、視覺化和即時回饋設計。

這個首頁用作個人 GitHub Pages 入口，集中連結不同 repository 內的 HTML 教材、課堂活動及學校行政工具，讓使用者能以關鍵字或分類快速尋找合適資源。
